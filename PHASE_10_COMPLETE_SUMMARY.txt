🚀 QUICK START

1. Install Redis:
   Windows: wsl + sudo apt install redis-server
   macOS:   brew install redis
   Linux:   sudo apt install redis-server

2. Start Redis:
   redis-server

3. Configure reCAPTCHA:
   • Go to https://www.google.com/recaptcha/admin
   • Create reCAPTCHA v3 site
   • Add localhost to domains
   • Copy keys to backend/.env

4. Update .env:
   REDIS_URL=redis://localhost:6379
   RECAPTCHA_SECRET_KEY=your_secret_key
   RECAPTCHA_SITE_KEY=your_site_key
   TWO_FACTOR_APP_NAME=MedCore BD

5. Start Services:
   Terminal 1: redis-server
   Terminal 2: cd health-care/backend && npm run dev
   Terminal 3: cd health-care && npm run dev

6. Test 2FA:
   • Login as admin
   • Go to http://localhost:3000/admin/security
   • Enable 2FA and scan QR code

🐛 TROUBLESHOOTING

Common Issues:

1. "Redis connection failed"
   → Check if Redis is running: redis-cli ping
   → Start Redis: redis-server
   → App continues without cache (degraded mode)

2. "CAPTCHA verification failed"
   → Verify RECAPTCHA_SECRET_KEY in .env
   → Check domain is registered in reCAPTCHA admin
   → Ensure frontend sends recaptchaToken

3. "Too many login attempts"
   → Wait 15 minutes
   → Or clear Redis: redis-cli DEL rate-limit:login:127.0.0.1
   → Or set NODE_ENV=development to disable

4. "Invalid 2FA token"
   → Check server time is synchronized (NTP)
   → Verify authenticator app time is correct
   → Try the next code (30-second window)
