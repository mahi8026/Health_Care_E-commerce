🐛 TROUBLESHOOTING
┌──────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│  Problem: Can't find "Add New" button                                       │
│  Solution: Make sure you're on "Environment Variables" page, not "General"  │
│                                                                              │
│  Problem: Variable added but loading still not visible                      │
│  Solution: Did you redeploy? Variable needs redeploy to take effect         │
│                                                                              │
│  Problem: Redeployed but still not working                                  │
│  Solution: Clear browser cache (Ctrl + Shift + Del) and hard refresh (F5)  │
│                                                                              │
│  Problem: Deployment failed with errors                                     │
│  Solution: Click the failed deployment, read logs, try redeploying again    │
│                                                                              │
│  Problem: Don't have access to Vercel dashboard                             │
│  Solution: Ask the project owner to add you or give you the login           │
