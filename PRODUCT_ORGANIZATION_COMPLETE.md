## 🐛 Troubleshooting

### **Issue: Products not showing in new categories**
**Solution:** Hard refresh browser (`Ctrl + Shift + R`) or clear cache

### **Issue: Category pages not loading**
**Solution:** Check if category slug exists in database, restart frontend server

### **Issue: Want to move products to different category**
**Solution:** 
1. Go to admin panel → Products
2. Click "Edit" on product
3. Change category dropdown
4. Save

### **Issue: Want to add more categories**
**Solution:** Edit `setup-recommended-categories.js` and run again

## 🔄 Rollback Plan (If Needed)

If something goes wrong, you can rollback using MongoDB:

```javascript
// Restore from backup (if you have one)

```

**Note:** All scripts are non-destructive — they only update category field, don't delete data.
