⚙️ REDIS SETUP (REQUIRED)

Option 1: Local Development (Docker - Easiest)
  docker pull redis:latest
  docker run --name health-care-redis -p 6379:6379 -d redis:latest

Option 2: Local Development (Native)
  # Windows: Download from https://github.com/microsoftarchive/redis/releases
  # Mac: brew install redis
  # Linux: sudo apt-get install redis-server

Option 3: Cloud (Production)
  • Redis Cloud: https://redis.com/try-free/ (30MB free)
  • AWS ElastiCache
  • Azure Cache for Redis

Environment Variables (add to backend/.env):
  REDIS_HOST=localhost
  REDIS_PORT=6379
  REDIS_PASSWORD=
