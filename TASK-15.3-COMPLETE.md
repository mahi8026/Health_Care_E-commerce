## How It Works

1. **Developer stages files**: `git add <files>`
2. **Developer commits**: `git commit -m "message"`
3. **Husky triggers**: Pre-commit hook runs automatically
4. **Lint-staged executes**:
   - Detects which staged files match patterns
   - Runs appropriate ESLint command for each workspace
   - Auto-fixes issues where possible
5. **Decision**:
   - ✅ If no errors/warnings: Commit proceeds
   - ❌ If errors/warnings remain: Commit is blocked

## Benefits

✅ **Consistent Code Quality**: All committed code meets linting standards
✅ **Fast Feedback**: Catch issues before they reach CI/CD
✅ **Automatic Fixes**: Many issues are auto-fixed without manual intervention
✅ **Selective Linting**: Only lints changed files, not the entire codebase
✅ **Team Alignment**: Everyone follows the same code standards
✅ **CI/CD Efficiency**: Fewer failed builds due to linting issues

```bash

# ✅ Commit succeeds after fixes
```

